# Maka Browser Icon Candidates

These are preview-only candidates. The active app icon and sidebar logo should be replaced only after one candidate is selected.

## Options

1. `01-m-shield-window.png` - security-first M mark with a browser window and shield.
2. `02-m-fingerprint.png` - fingerprint-ridge M mark, closest to the previous identity-isolation visual language.
3. `03-m-orbit-node.png` - minimal M monogram with a controlled profile node, strongest at small taskbar sizes.
4. `04-m-profile-windows.png` - multi-window M mark, strongest match for multi-profile and multi-store operations.
5. `05-m-orbit-emerald.png` - refined version of option 3 with a brighter emerald M and silver route ring.
6. `06-m-orbit-titanium.png` - titanium M with cyan route ring, more premium and desktop-native.
7. `07-m-orbit-pearl.png` - pearl M, gunmetal route ring, coral endpoint; quietest executive direction.
8. `08-m-window-champagne.png` - champagne M inside nested browser frame, more explicit browser metaphor.
9. `09-m-route-azure.png` - azure M with partial route/check arc, strongest energy and launch feel.

## Recommended Default

Use `03-m-orbit-node.png` as the baseline visual direction.
Use `06-m-orbit-titanium.png` if the final icon should feel most polished and native.
Use `07-m-orbit-pearl.png` if the final icon should feel most premium and restrained.
